sruti — release notes
=====================

Version 0.2.0 (2026-10-04)
---------------------------
- Phase v0.2 — Prove the piece model.
- SRUTI-005: three golden examples in one format — 001 Italian ragchew, 002 DJ0YI's POTA activation,
  003 E72U's contest run — with a reference gloss and message per piece and a Ukrainian session
  reference (drafted with Claude Opus 5.5 by poc/explain_session.py, approved by the owner).
- SRUTI-006: poc/eval_golden.py runs the piece explainer over the golden examples, checks schema,
  budget, coverage, invented call signs and guessed unreadable text, and writes a side-by-side report;
  --live opt-in, --selftest offline, --rescore without new calls.
- SRUTI-007: five live gemini-3.8-flash runs. Decision: the hints glossary (glossary/cw-hints.md) with
  the settled prompt — 15/15 pieces pass, 1.5–4.1 s, ~$0.0026 per piece. Contest and POTA conventions
  added to both glossaries. The prompt, the glossary form and the measured figures are in ARCHITECTURE
  §The two tiers; the runs in poc/RESULTS.md. 002's reference corrected to the 559 report the model read.
- Code review: 7 findings, 2 fixed (a "(?)" no longer excuses an invented call sign; rescore refuses
  changed pieces and keeps the run time), 5 deferred to v1.4 and v1.6.

Version 0.1.0 (2026-10-04)
---------------------------
- Phase v0.1 — Text from the receiver, decoded on the Mac.
- Specification: MISSION, ARCHITECTURE, ROADMAP (v0–v2), the design brief and the Claude Design
  deliverable, the ports & perimeters diagram; delivery skills adapted from matrix-agora.
- PoCs: the Gemini piece-tier model comparison; the pywebview desktop window.
- SRUTI-001: kiwiclient has no license — only the spike uses it, from an uncommitted checkout; the
  product writes its own receiver client.
- Re-plan: the receiver's CW_decoder extension was missing or silent, so sruti decodes CW on the Mac;
  ROADMAP adds v1.2 The CW decoder.
- SRUTI-004: prototype CW decoder (poc/receiver/cw_decode.py) — tone search inside the filter, adaptive
  threshold, noise-proof speed estimate, bias-aware gap thresholds, prosigns, [err] for unknown codes;
  self-test 10/10. The spike connects like the browser page, tunes to the signal's own frequency,
  records WAV and decodes it on the Mac; --passband, --seconds, --scan.
- SRUTI-002: fixtures cq (DJ0YI calling CQ POTA, 7033.05 kHz) and conversation (E72U's contest run,
  7027.50 kHz) from Trémolat, confirmed by the owner; captures mask the owner's IP and keep only the size
  of the receiver's configuration blobs.
- SRUTI-003: message inventory — 43 message types, all documented in ARCHITECTURE §The receiver.
- Code review: 11 findings, 5 fixed, 6 deferred to v1.1, v1.2, v2 and the backlog.
- Moved by the owner: the 14.100 MHz beacon recording and its check, to v1.2 (20 m was closed during
  the v0.1 recording window).
