# sruti

A listening agent: it tunes into a public WebSDR receiver, reads the Morse code (CW) it hears as text, and explains in real time — in Ukrainian — what is being said and what is going on. A local LLM gives the instant gist of each transmission; Claude periodically gives the full picture of the conversation.

*Śruti* is Sanskrit for "that which is heard".
